# Math4Siblings 🦔

A colorful, meme-fueled math practice game built in Godot 4, made for my younger siblings (K-3 level) to practice addition and subtraction in a fun, low-pressure way.

## What it does

- Randomly generates addition/subtraction questions, scaled to a K-3 difficulty range
- Multiple-choice answers (tap, don't type) so it's accessible for early readers
- ❤️ 3-life system — lose a life on a wrong answer, game over when hearts run out
- 🔥 Streak tracking — get 5 in a row right and the difficulty ramps up
- 😂 A meme-style "fail screen" (funny text + sound effect) pops up on wrong answers before the next question loads, keeping mistakes light and funny rather than punishing
- 🎉 Mascot reactions, color-flash feedback, and bouncy button animations for extra juice
- 🔄 Play Again button to restart instantly after Game Over

## How to run it

### Option 1: Play in browser (if hosted)
Open the itch.io / hosted link (if provided).

### Option 2: Run from source in Godot
1. Install [Godot 4.x](https://godotengine.org/download)
2. Clone this repo
3. Open Godot, click "Import," and select the `project.godot` file in this repo
4. Press the Play button (▶) or `F5`
