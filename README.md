# Math4Siblings 🦔

Just a simple rapid-fire low cortisol maths game, inspired by my siblings' maths score. Primarily built for K3 education level, will be working on advancing the difficulty! 

## How to run it

### Option 1: Play in browser (if hosted)
Open the itch.io / hosted link (provided).

### Option 2: Run from source in Godot
1. Install [Godot 4.x](https://godotengine.org/download)
2. Clone this repo
3. Open Godot, click "Import," and select the `project.godot` file in this repo
4. Press the Play button (▶) or `F5`

## Tech stack

- **Engine:** Godot 4.7 (GDScript)
